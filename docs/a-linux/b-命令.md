# Linux终端使用

学习Linux操作系统的使用，主要就是学习终端命令的使用。

* Linux操作系统主要是在服务器、嵌入式中流行，目标人群是专业的开发人员。
* 如果使用图形界面系统和Windows系统没有区别。
* 互联网前、后端产品的部署，数据库的操作，都是通过SSH客户端操作服务器来完成的。
* Linux 行版本的命令大概有200多个，但是常用的命令差不多只有10个。

## 终端命令格式

```shell
command [-options] [parameter]
```

* `command`（命令名）：相应功能的英文单词或单词的缩写。
* `[-options]`（选项）：可用来对命令进行控制，也可以省略。
* `parameter`：传给命令的参数，可以是零个、一个或者多个。

> [!warning]
>
> 借助大语言模型，可以快速查阅Linux终端命令含义及其用法。

### 常用命令

| 命令             | 对应英文             | 作用                     |
| :--------------- | :------------------- | :----------------------- |
| `ls`             | list                 | 查看当前文件夹下的内容   |
| `pwd`            | print wrok directory | 查看当前所在文件夹       |
| `cd [目录名]`    | change directory     | 切换文件夹               |
| `touch [文件名]` | touch                | 如果文件不存在，新建文件 |
| `mkdir [目录名]` | make directory       | 创建目录                 |
| `rm [文件名]`    | remove               | 删除指定的文件名         |
| `clear`          | clear                | 清屏                     |

### 终端常用技巧

1. 自动补全：使用`Tab`按钮，可以补全未完成的命令：
   * 如果输入的没有歧义，系统会自动补全。
   * 如果存在多种可能性，系统会提示可能存在的命令。
2. 使用`up`和`down`可以在历史命令之间进行切换。
3. `ctrl + c`可以强制退出特殊状态。

## 目录操作

Linux文件或目录名，最长为256个字符。

### 查看目录

Linux中的目录就是桌面系统中的文件夹，使用`ls`可以查看目录下的内容。`ls`命令常用的选择有三个

* `-a`显示指定目录下所有子目录与文件，包括隐藏文件。
* `-l`以列表方式显示文件的详细信息。
* `-h`配合`-l`以人性化的方式显示文件大小。

```shell
ls -a -l -h
```

<img src="https://raw.githubusercontent.com/hughxusu/lesson-knowledge/develop/images/linux/Xnip2026-04-04_10-03-11.jpg" style="zoom:60%;" />

执行命令时选项可以写在一起，且没有顺序要求

```shell
ls -alh
```

文件大小单位对照表

| 单位 | 英文          | 含义                                           |
| :--- | :------------ | :--------------------------------------------- |
| 字节 | B（Byte）     | 在计算机中作为一个数字单元，一般为8 二进制数。 |
| 千   | K（Kibibyte） | 1 KB = 1024 B，千字节 （$1024 = 2^{10}$）。    |
| 兆   | M（Mebibyte） | 1 MB = 1024 KB，百万字节。                     |
| 千兆 | G（Gigabyte） | 1 GB = 1024 MB，十亿字节，千兆字节。           |
| 太   | T（Terabyte） | 1 TB = 1024 GB，万亿字节，太字节。             |
| 拍   | P（Petabyte） | 1 PB = 1024 TB，千万亿字节，拍字节。           |

### 通配符的使用

通配符（Wildcards）是一种特殊的字符，用来代替一个或多个未知的字符。

| 通配符  | 含义                             |
| :------ | :------------------------------- |
| `*`     | 代表任意数数字符                 |
| `?`     | 代表任意一个字符                 |
| `[]`    | 表示可以匹配字符组中的任一一个   |
| `[abc]` | 匹配a、b、c中的任意一个          |
| `[a-f]` | 匹配从a到f范围内的的任意一个字符 |

创建多个文件

```shell
touch python.txt js.txt html.txt css.txt c++.txt c.txt
```

1. 定位文件名以`c`开头的文件

```shell
ls c*.txt
```

2. 定位文件名以`s`结尾的文件

```python
css.txt	js.txt
```

3. 定位包含字符`t`的文件

```shell
ls *t*.txt
```

4. 选择以`c`开始，只有三个字符的文件名

```shell
ls c??.txt
```

5. 筛选出以`j`、`p`和`h`开始的文件

```shell
ls [jph]*.txt
ls [h-p]*.txt
```

### 切换目录

`cd`命令可以更改当前的工作目录

* `cd`或`cd~`切换到当前用户的主目录。

<img src="https://raw.githubusercontent.com/hughxusu/lesson-knowledge/develop/images/linux/Xnip2026-04-04_10-56-46.jpg" style="zoom:60%;" />

* `cd .`保持在当前目录不变。
* `cd ..`切换到上级目录。
* `cd -`可以在最近两次工作目录之间来回切换。

绝对路径和相对路径

* 绝对路径：表示从根目录`/`或`~`主目录开始，到某个文件的距离路径。
* 相对路径：表示相对当前目录所在的目录位置。

### 创建和删除

`mkdir`创建一个新的目录

* `-p`可以递归创建目录

```shell
mkdir -p a/b/c
```

> [!alert]
>
> 新建目录的名称，不能与当前目录中，已有的目录同名。

`rm`可以用于删除文件或目录

* `-f`强制删除，不存在的文件命令不会报错。
* `-r`递归地删除目录下的内容，删除文件夹时必须加此参数。

删除文件可以与通配符配合使用

```shell
rm c*.txt   
```

递归删除多个文件夹

```shell
rm -r a
```

> [!alert]
>
> 使用命令删除文件不会放入回收站，无删除后无法找回。

### 查看文件结构

`tree`命令可以以树状图列出文件目录结构，`tree`命令在默认的Mac电脑和Linux服务器上是没有安装的。Mac电脑可以通过[Homebrew](/docs/b-mac/mac配置?id=homebrew安装及常用命令)安装该命令，Linux可以使用命令行安装。

* `-d`只显示目录。
* `L`控制树状结构的级别。

只显示1级目录

```shell
tree -L 1
```

### 拷贝和移动

`cp`命令可以用于文件和目录的复制

* `-i`文件覆盖前提示。
* `-r`递归复制该目录下的所有子目录和文件。

1. 复制一个文件

```shell
# 命令    [源文件]    [目标文或文件夹]
  cp     naz1.jpg    a/
```

2. `cp`命令复制目标文件存在，会直接覆盖不会提示

```shell
cp nazs/naz2.jpg a/naz1.jpg
```

3. 使用参数`-i`覆盖文件时会提示

```shell
cp -i nazs/naz3.jpg a/naz1.jpg
```

4. 复制整个文件目录

```shell
cp -r a d
```

`mv`命令可以用于文件和目录的移动

* `-i`覆盖文件前提示

1. 移动文件或文件夹，不会保留源文件

```shell
# 命令    [源文件]    [目标文或文件夹]
  mv     naz1.jpg    a/b
```

2. 使用参数`-i`覆盖文件时会提示

```shell
mv -i naz1.jpg a
```

3. 文件夹可以直接移动不需要参数

```shell
mv nazs a
```

4. `mv`可以用来对文件或文件夹重命名

```shell
mv naz1.jpg naz2.jpg
```

## 文件操作

### 创建文件

`touch`命令可以创建文件

* 如果文件不存在，创建一个空文件。
* 如果文件已经存在，可以修改文件的末次修改日期。

### 查看文件内容

`cat`查看文件内容，该命令会一次显示所有的内容，适合查看内容较少的文本文件。

* `-b`对非空输出行编号。
* `-n`对输出的所有行编号。

`more`可以用于分屏显示文件内容，每次只显示一页内容，适合于查看内容较多的文本文件。

* `up`和`down`上下滚动。
* `Enter`向下滚动。
* `b`和`f`前一屏和后一屏。
* 空格键是下一屏。
* `q`退出。

### 搜索文件内容

`grep`允许对文本文件进行查找，且支持正则表达式。

* `-n`显示匹配行及行号。
* `-v`显示不包含匹配文本的所有行。
* `-i`忽略大小写。

1. 查找文件中的内容

```shell
# 命令  [查找内容]  [查找文件]
grep      桃花     one.txt
```

2. 显示查的内容和行号

```shell
grep -n 桃花 one.txt 
```

3. 显示没有匹配内容和行号

```shell
grep -nv 桃花 one.txt
```

4. 如果搜索内容也可以用`""`表示，可以匹配空格。

```shell
grep -n "桃 花" one.txt 
```

## 重定向和管道

### 在终点中打印

`echo`命令可以将字符串内容打印在屏幕上

```shell
echo hello world
```

> [!warning]
>
> 单独使用`echo`命令没有意义，一般和重定向联合使用。

### 重定向

`>`将内容输出到文件中，会覆盖文件原有的内容。

1. 直接将输入内容保存到文件中

```shell
echo hello world > hello.txt
```

2. 将命令执行结果保存到文件中

```shell
tree > tree.txt
```

`>>`追加内容到文件中，会将内容追加到已有文件的末尾。

```shell
echo hello linux >> hello.txt
```

### 管道

管道就是将 一个命令的输出做为另一个命令的输入，使用`|`表示。使用管道时，至少要两个命令。

1. 分屏显示查询结果

```shell
ls -alh | more
```

2. 在查询结果中搜索，并保存搜索结果，筛选出所有隐藏文件

```shell
ls -alh | grep " \." > ~/Desktop/result.txt
```

* `.`在正则表达式中有特殊含义所有用`\.`。
* 前面的空格避免匹配到其他文本中的`.`。
